# 文游·文字脚本格式（Text Script Format）

> 橙光风格的纯文本剧本格式。作者只写文字脚本，用 `demo_gl/tools/tsc.py`
> 一键编译成引擎剧本 JSON：
>
> ```
> cd demo_gl
> python tools/tsc.py scripts/我的剧本.txt -o scripts/我的剧本.json   # 编译
> python tools/tsc.py scripts/我的剧本.txt --check                    # 只校验
> python tools/tsc.py --demo                                          # 打印内置示例
> ```

设计原则：**一行一意、符号驱动、中文友好**。空行随意，看着像小说的东西就是正文。

---

## 0. 总览

| 行首符号 | 含义 |
|---------|------|
| `//` | 注释（整行忽略） |
| `#` | 头部信息：`# 标题 xxx`、`# 作者 xxx` |
| `@角色` / `%属性` | 角色定义 / 属性定义 |
| `==场景` | 新场景开始（直到下一个 `==场景` 或文件结束） |
| `@角色id` | 场景内：角色站位 |
| `?` | 选项块开始，其后每行 `>` 是一个选项 |
| `!` | 指令行：`!set` / `!show` / `!调查` |
| `->` | 跳转指令 |
| `::结局` | 结局指令 |
| 其它 | 旁白（直接一行）或 `角色(表情): 对白` |

---

## 1. 头部

文件最前面，顺序随意：

```
# 标题 灯下问仙
# 作者 阿灯
```

- 标题必填，作者可省。

### @角色 定义

```
@角色 su 苏璃 #FFB6C1 立绘=su
@角色 shen 沈青 #87CEEB
```

- 字段顺序：`@角色 <id> <显示名> <名字框颜色> [立绘=<前缀>]`
- `立绘=` 省略时前缀取角色 id。
- 自动生成五表情立绘映射：`chars/<前缀>_normal.png`、`_smile`、`_angry`、`_sad`、`_surprise`。
- **角色 id 只能用英文字母/数字/下划线**（引擎限制）。

### %属性 定义

```
%属性 favor 苏璃好感 0 0 100 #FFB6C1
%属性 xiuwei 修为 0 0 100 #87CEEB
```

- 字段顺序：`%属性 <id> <显示名> <初值> <最小> <最大> <进度条颜色>`
- 编译为剧本 JSON 的 `attrs` 条目（引擎自动做 clamp、变动提示）。
- 属性 id 同样只能用英文字母/数字/下划线。
- 没定义过的变量也能用（按 0 初始化），但**选项条件里引用未定义变量时编译器会告警**。

---

## 2. 场景

```
==场景 s1_town 背景=town_day 音乐=town_day 音效=wind_chime 存档点
==场景 s3_test 背景=bamboo_night 进入条件="xiuwei>=20 || favor>=10" 条件跳转=s3_fallback
```

- 第一个参数是场景 id（英文/数字/下划线，必填、唯一）。
- 后面是空格分隔的 `键=值` 参数，顺序随意：

| 参数 | 说明 |
|------|------|
| `背景=xxx` | 背景图。写裸文件名自动补 `bg/` 前缀；`背景=none` 纯黑；不写=沿用上场 |
| `音乐=xxx` | BGM，裸文件名自动补 `bgm/` 前缀 |
| `音效=a,b` | 音效，逗号分隔多个，自动补 `sfx/` 前缀 |
| `存档点` | 无值标记：进入此场景自动存档 |
| `进入条件=表达式` | 不满足时跳 `条件跳转` 指定的场景（都没写则顺延下一场景） |
| `条件跳转=场景id` | 配合 `进入条件` 使用 |

- 条件表达式里**含空格时必须加引号**：`进入条件="favor>=10 && xiuwei>=20"`；不含空格可裸写 `进入条件=favor>=10`。

### 条件表达式

支持 `==` `!=` `>` `<` `>=` `<=` `&&` `||` `!` `()`、数值、变量、`true`/`false`。
变量名只能英文/数字/下划线，未定义按 0 处理。以下所有 `[条件]` 都是这套语法。

---

## 3. 站位

场景体内的 `@` 行（区别于头部的 `@角色` 定义行）：

```
@su normal center        " 简易站位：left / center / right（三槽 pos 写法）
@su 微笑 right           " 表情可用中文别名
@su 微笑 far-left        " 远侧预设位：far-left / far-right（自动转自由位）
@su 微笑 left 近景       " 景别词：远景 / 中景 / 近景（也可写 far / mid / close 或裸数字缩放）
@mo angry 0.3,1.0,0.85   " 自由坐标：x,y,scale（0-1 比例，scale 0.3-2.0）
```

**预设五位**（y 一律 1.0 全身）：

| 站位 | far-left | left | center | right | far-right |
|------|----------|------|--------|-------|-----------|
| x    | 0.10     | 0.28 | 0.50   | 0.72  | 0.90      |

**景别三档**：远景/far → scale 0.75（多人/群像） · 中景/mid → 0.85（默认） · 近景/close → 1.0（独白/情绪）。

规则：
- `left/center/right` 单独使用时保持三槽 `pos` 写法（向后兼容）。
- `far-left/far-right` 或**一旦带景别词/裸数字缩放**，一律编译为自由位 `{x, y:1.0, scale}`
  （三槽 pos 没有 scale）；不写景别时默认中景 0.85。
- 景别词也可单独写：`@su 微笑 近景` 等于 center 近景（x=0.50, scale=1.0）。
- 自由位 `x,y,scale` 写法原样保留，但已含缩放，**不能再叠加景别词**（报错带行号）。
- 非法站位参数会报错并标注行号。

表情中文别名：平常/普通/平静→normal，微笑/笑/开心→smile，生气/怒→angry，
难过/悲伤/伤心→sad，惊讶/吃惊→surprise。也可直接写英文表情名。

## 4. 正文

```
雨从那年就开始下了，一直下到你回到灯溪镇。     ← 旁白：直接一行
苏璃(微笑): 阿灯！你回来啦！                  ← 对白：角色(表情): 台词
沈青: 出剑吧。                                ← 表情可省略，按 normal
你怀里有{favor}点好感、{xiuwei}点修为。        ← {变量} 插值
夜深了，灯笼一盏盏熄了。 [favor>=10]          ← 行尾 [条件]：不满足则该行跳过
```

- 角色可写 **id 或显示名**（编译器解析为 id；未定义的角色报错）。
- 冒号中英文都行（`:` `：`）。
- 说话人没站位时引擎自动补一个空槽位。

---

## 5. 选项

`?` 行开始一个选项块，下面每行 `>` 一个选项：

```
?
> 陪她放灯 {favor+6} -> s2_lantern
> 去竹林闭关 {xiuwei+15} -> s2_bamboo
> 直接闯山门 [xiuwei>=20] -> s3_test
> 什么也不做
```

一个选项的完整结构（四段都可有可无，但顺序固定）：

```
> 选项文本 [条件表达式] {变量操作} -> 目标场景
```

- `[条件]`：不满足时该选项**灰显不可点**（引擎原生 disabled 行为）。
- `{变量操作}`：选中后执行，空格或逗号分隔多个：
  - `favor+5` / `favor-3`：增量
  - `gold=100` / `flag=1`：直接赋值
- `-> 目标`：选中后跳转的场景 id；**不写 `->` 则顺序继续当前场景的下一行**。

---

## 6. 指令

```
!set favor+5 gold=100        " 立即修改变量（语法同选项的 {} 段）
-> s_next                    " 无条件跳转
-> s_next [flag==1]          " 条件跳转：条件不满足时该指令跳过，继续下一行
::结局 灯火良缘               " 打出结局（结局名记入结局收集）
!show sword_light            " 展示 CG，裸文件名自动补 cg/ 前缀
!调查 0.42,0.62,0.16,0.18 图=teacup 文=粗陶茶盏，有一道旧磕痕。
```

- `!调查` 参数：`x,y,w,h`（视口比例 0-1）+ `图=`（可省）+ `文=`（可省）。
- `文=` 后面的内容可以带空格，一直到行尾。

---

## 7. 编译期校验

`tsc.py` 编译时检查（**错误**带行号、中文，编译中止）：

- 语法：行格式、场景 id 重复、括号不匹配、数值非法
- 条件表达式语法（内置递归下降解析器，不用 eval）
- 未定义的场景引用（`->` / 选项 goto / 条件跳转）
- 未定义的角色（站位 / 对白说话人）
- 结局可达性：从第一个场景出发，至少能走到一个 `::结局`

**告警**（不中止编译）：

- 选项 `[条件]` 里引用了未在 `%属性` 定义过的变量
- 定义了却从未使用的角色 / 属性

## 8. 完整示例

下面是一个可以直接编译的完整剧本（也可 `python tools/tsc.py --demo` 查看）：

```
// 灯下问仙 · 文字脚本示例
# 标题 灯下问仙
# 作者 文游工坊

@角色 su 苏璃 #FFB6C1 立绘=su
@角色 shen 沈青 #87CEEB 立绘=shen
@角色 tang 阿棠 #E8C47E 立绘=tang

%属性 favor 苏璃好感 0 0 100 #FFB6C1
%属性 xiuwei 修为 0 0 100 #87CEEB

==场景 s1_town 背景=town_day 音乐=town_day 音效=wind_chime 存档点
@su normal center
你回到灯溪镇的那天，风里都是灯油的味道。
苏璃(微笑): 阿灯！三年不见，你回来啦！
苏璃(惊讶): 你怀里……还揣着那只没做完的兔子灯？
?
> 陪她放灯 {favor+6} -> s2_lantern
> 去竹林闭关 {xiuwei+15} -> s2_bamboo
> 直接闯山门 [xiuwei>=20] -> s3_test

==场景 s2_lantern 背景=lantern_shop 音乐=shop_warm
@su smile left
灯笼铺里，苏璃把竹骨一根根剖开。
苏璃(微笑): 帮我拉住灯口，别动。
!调查 0.42,0.62,0.16,0.18 图=teacup 文=粗陶茶盏，盏底有一道旧磕痕。
?
> 买下那只兔子灯送她 [favor>=5] {favor+6} -> s3_test
> 默默离开 -> s3_test

==场景 s2_bamboo 背景=bamboo 音乐=bamboo_wind 音效=bamboo_rustle
@shen normal right
竹林深处，沈青收剑而立。
沈青: 闭关三日，可有长进？
!show sword_light
?
> 与沈青切磋 [xiuwei>=10] {xiuwei+10} -> s3_test
> 下山赴试 -> s3_test

==场景 s3_test 背景=bamboo_night 音乐=tense 存档点 进入条件="xiuwei>=20 || favor>=10" 条件跳转=s3_fallback
山门试炼，一剑问心。
你的修为是{xiuwei}，苏璃对你的好感是{favor}。
?
> 与苏璃归隐灯下 [favor>=12] -> s_end_love
> 拜入山门 -> s_end_join

==场景 s3_fallback 背景=teashelter_night 音乐=teashelter
@tang normal center
试炼落第。山脚下的茶棚还亮着灯。
阿棠(微笑): 客官，进来喝杯热茶吧。
::结局 归隐茶棚

==场景 s_end_love 背景=festival_night 音乐=festival
@su smile center
上元灯火如昼，兔子灯终于做完了。
苏璃(微笑): 这一次，不许再走啦。
::结局 灯火良缘

==场景 s_end_join 背景=bridge_sunset
山门晨钟暮鼓，从此青灯相伴。
::结局 青灯问道
```

编译：

```
python tools/tsc.py 示例.txt -o 示例.json
# [完成] 编译成功：8 个场景，3 个结局 → 示例.json
```

## 9. 网页端直接用（无需 Python）

引擎内置了浏览器版编译器 `demo_gl/tsc.js`（与 `tools/tsc.py` 同规则、同错误格式），
手机/电脑双击打开 `index.html` 即可「文字脚本即玩」：

- **标题页「文字脚本示例」按钮**：点击直接把内置示例《灯下问仙》（同
  `scripts/demo_branch.txt`）在浏览器里编译并载入，零准备体验分支剧情 + 数值门控。
- **标题页「载入剧本」按钮**：文件选择器同时接受 `.json` 与 `.txt`；
  选 `.txt` 时先经 `window.TextScript.compile` 编译，报错弹窗带行号中文，
  编译产物与 Python 版完全一致。
- 开发者也可在控制台直接用：`TextScript.compile(文本)` → `{ script, warnings }`，
  校验失败 throw 带全部行号的 Error。

与 Python 版的唯一差异是素材解析：浏览器读不了文件系统，裸文件名（如 `背景=town_day`）
按「当前已加载剧本引用过的素材清单」做 stem 匹配取真实扩展名；清单之外按默认扩展名输出
（图片在 dist 环境自动用 `.webp`，探测逻辑同 ai_gen.js），引擎对缺失素材照常降级占位。

## 10. AI 生成与文字脚本的配合

网页端「AI 写新故事」（`demo_gl/ai_gen.js`）与文字脚本是一条流水线的两端：

- **AI 生成 → JSON**：模态框里填题材/角色（或用「快速模板」chips 一键填好），
  生成结果是剧本 JSON，可直接开玩或「下载剧本 JSON」保存。
  生成表单的「查看脚本示例」面板展示的就是文字脚本格式（取自 `tsc.js` 内置
  DEMO《灯下问仙》，即本文档第 1-8 节的完整示例）。
- **JSON → 文字脚本续改**：两者结构一一对应（scene↔`==场景`、say↔`名字(表情):`、
  choice↔`?`+`>`、require↔`进入条件`、end↔`::结局`）。想继续改 AI 生成的剧情，
  推荐参照示例把 JSON 改写成文字脚本维护，再用 `tools/tsc.py`（或标题页
  「载入剧本」直接选 `.txt`）编译回 JSON。
- 结果面板的「自检摘要」行会给出校验/修复/素材映射统计，生成质量一目了然。
