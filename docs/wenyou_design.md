# 文游设计稿 v1 —— 要素清单 · 帧模型 · 跳转 · 人物站位

> 本文是「她的山间灯火」引擎的设计基准。已实现的标 ✅，本轮新增的标 🆕，方向性规划标 🔭。

## 一、文游需要什么（要素清单）

| 层 | 要素 | 现状 |
|---|---|---|
| 叙事 | 旁白 / 对白 / 内心独白 | ✅ narrate/say（独白用 narrate 斜体） |
| 分支 | 选项、条件选项、场景分流、多结局 | ✅ choice/goto/require/end |
| 数值 | 属性（好感/修为…）、增减、条件判断、联动 | ✅ attrs + set + if 表达式 |
| 演出 | 背景、立绘表情、CG、转场、调查热点 | ✅ bg/chars/cg/inspect，黑场转场 |
| 声音 | BGM（片段循环）、音效、配音 | ✅ 19 个免费素材已接入 |
| 系统 | 存档/读档、回看、自动、跳过、设置、画廊、结局收集 | ✅ |
| 制作 | 文字脚本、可视化编辑器、AI 一键生成、素材上传 | ✅ tsc + 剪辑式编辑器 + AutoNovel |
| 发布 | PWA（手机一键玩/离线）、自动部署 | ✅ GitHub Pages + Actions |

缺口/可优化：帧级预览（编辑器现在是指令列表思维，不是画面思维）🔭、转场类型单一 🔭、人物站位只有 3 槽+自由坐标（无可视化参考线）🔭。

## 二、核心心智模型：场景 = 一段视频，指令 = 帧

把每个场景当作一段「影片」，影片由**帧（Frame）**组成：

```
场景 s1_ferry（影片）
 ├─ 帧 1  [背景:渡口夜雨] [人物:无]        [声:雨声+船吱呀]  旁白:雨是从那年…
 ├─ 帧 2  [背景:同上沿用] [人物:苏璃·左·入]               苏璃:阿灯！
 ├─ 帧 3  [背景:同上]     [人物:苏璃·左, 沈青·右·淡入]    沈青:……
 └─ 帧 4  [分支帧 🔀]     选项A→影片《帮苏璃》 选项B→影片《追沈青》
```

一帧 = 一条 script 指令 + 该指令时刻的**画面快照**（背景、在场人物及位置表情、声音）。编辑器应以帧为最小单位：

- **帧是画面，不是文字**：编辑器时间轴上每帧渲染真实缩略画面（背景+立绘合成），像剪映的片段缩略图，一眼看出"这帧长什么样"
- **帧可拖、可插、可剪**：拖帧=重排，点帧间隙插入新帧，右键剪除（已有基础，升级为画面帧）
- **连续帧只记差异**：背景/人物/声音"沿用上一帧"（与现有 schema 的省略=沿用一致），帧缩略图上用角标标出本帧变化（新人物入场▲、换人▼、换背景🖼）

## 三、跳转逻辑（帧与帧、影片与影片）

```
线性播放:  帧1 → 帧2 → 帧3 …  （场景内顺序）
帧内跳转:  goto [条件] →目标场景   （影片级跳剪）
分支帧:    choice ─ A → 场景X   （每选项一条分镜）
                  └ B(条件) → 场景Y
门禁帧:    require 满足→本片 / 不满足→require_else 影片（数值分流）
终点帧:    end → 结局收集
```

可视化规则（编辑器分支图升级版）：
- 帧缩略图下画**跳转箭头**：→场景名 直接印在帧卡上，点了能改
- 条件分支帧用**菱形角标**，达标线绿色、未达标线灰色
- 悬空跳转（目标不存在）帧卡红边框告警（编辑器实时校验）
- 场景卡之间的**分镜连线图**（现有分支图升级为缩略图节点+箭头，🆕本轮做简易版：文字节点图→帧缩略图节点图）

## 四、人物放哪、怎么放（站位系统）

**预设位（推荐 90% 情况）**——三档五位的舞台栅格：

```
        左        左中       中       右中       右
  ┌─────────┬─────────┬─────────┬─────────┬─────────┐
  │ far-left│  left   │ center  │  right  │far-right│   y=1.0 全身
  │ x=0.10  │ x=0.28  │ x=0.50  │ x=0.72  │ x=0.90  │
  └─────────┴─────────┴─────────┴─────────┴─────────┘
   远景 scale .75（多人/群像） · 中景 .85（默认） · 近景 1.0（独白/情绪）
```

- 经典 3 槽 left/center/right 是预设位的子集，向后兼容
- 双人对话：left+right；三人：left+center+right；四人以上加 far 位
- **焦点规则**：说话人亮度 100%、其他人压暗（已有），近景只留一人

**自由位（精细调整）**：画布直接拖拽（已有）+ 本轮加：
- 🆕 **吸附**：拖到预设位附近（±3%）自动吸附并对齐 y=1.0 底线
- 🆕 **参考线**：画布显示淡色五格竖线+底线，拖角色时高亮最近格
- 🆕 **缩放滑杆**：点选角色后底部滑杆调 scale（0.5-1.2），实时预览
- 越界保护：x∈[0.02,0.98]，y∈[0.7,1.2]，松手自动夹紧

**入场/出场（帧间人物变化）**：fade / slide（已有）；帧缩略图角标：▲入场 ▼出场。
